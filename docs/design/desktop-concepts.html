Shelf + Widgets Chosen

The shelf from B keeps the left edge: drop zone, then the Desktop, Downloads and Recent stacks, fanning out to the right. Widgets move to the top right, under the tray, and there are only two: Today (date, weather, next events) and Now playing. Where the switch lives

Settings › Desktop

Right-click › Desktop settings opens this page. Desktop style picks between Shelf + widgets and Clean with two preview tiles. The rows below set the shelf (on or off, which edge, which stacks) and the widgets (on or off, which ones). With Clean chosen, the Shelf and Widgets groups grey out.

Earlier concepts

A, B and C as first proposed, kept for reference

Concept A

Widgets

A few glass islands sit on the wallpaper: today's date and next events, weather, the machine's vitals, what is playing. For glancing, not for files. You drag them where you want them and add or remove them from Edit widgets; the middle of the wallpaper stays empty.

Concept B

Shelf

No widgets. One slim island on the left edge does what a classic desktop is actually used for: a place to drop things and find them again. Drop a file on it to keep it; the stacks for Desktop, Downloads and Recent fan open on click, and the last row opens the folder in Files.

Dark · Downloads stack fanned open.

Light · a file dropped on the shelf, and the desktop right-click menu with New open.

Concept C

Clean

Wallpaper only; nothing stays on screen. Everything starts from right-click. While you drag a file anywhere, a drop pill slides in under the clock so you can save it to Desktop, Downloads or Documents, share it, or open it, and it leaves when the drag ends.

The other desktop style you can pick in Settings › Desktop. Shown: the right-click menu (hovered: Open Terminal here) and, separately, the drop pill as it looks mid-drag.

Mockup for review, not a build. Colour is never the accent: selection and hover use the text colour, so it holds with a pure black accent.
